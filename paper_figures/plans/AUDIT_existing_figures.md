## How this was measured

Each `tikz/<name>.tex` was rendered by a wrapper in `paper_figures/drafts/audit/`: `wrap_template.tex` produces `audit_<name>.tex` and `.png` (300 dpi). The wrapper `\input`s the clone's file unchanged and uses the paper's fonts and preamble. IEEEtran sets rm = Times `ptm`, sf = Helvetica `phv` and tt = Courier `pcr` (IEEEtran.cls:494-496). The packages, TikZ libraries and colors come from `bare_conf_compsoc.tex:327-352`. `\columnwidth` = 252 pt and `\textwidth` = 516 pt (VISUAL_LANGUAGE.md, "Page geometry"). Captions are dropped. Sizes are the rendered drawing box in pt; a box can include empty nodes, so ink can be a little smaller. In IEEEtran 10 pt, `\tiny` is 5 pt, `\scriptsize` 7 pt, `\footnotesize` 8 pt and `\small` 9 pt (IEEEtran.cls:657-660).

## Proposed conventions for program graphs (for VISUAL_LANGUAGE.md, if you agree)

- Listing in `\footnotesize\ttfamily`, with every token at a column that is a multiple of one typewriter character (`\setbox0=\hbox{\footnotesize\ttfamily 0}\edef\cw{\the\wd0}`), and a uniform 13 pt row pitch.
- ddi = an arc above the row, from the input operand to the output operand. rf = a line that drops a little below the source operand, runs in the gap between rows, and enters the target from above; a long rf runs down a rail to the right of every row.
- Flags (r, c) in a right-hand column, 8 pt roman, with a 7 pt italic key.
- A subset of rows (added, bound-to-squash, speculative) is marked with a left bracket and a 7 pt italic label, never with color or gray text (gray means defense-specific).
- Memory state in a tight sharp box (`inner sep=0.9pt`).
- Reference implementation: `paper_figures/drafts/_standalone_interleave_v3.tex`.
