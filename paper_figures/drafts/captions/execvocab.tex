\textbf{Execution-graph vocabulary shared by every SimSpect defense model.} An execution is a graph: instruction nodes in program order whose operands name abstract locations, three Boolean flags per instruction, and two operand-to-operand relations. \emph{Graph}: how Figs.~X and~Y draw each element; \emph{Alloy}: its name in the model. Only the defense block (speculation contract, protection set, leakage function) differs between models.
