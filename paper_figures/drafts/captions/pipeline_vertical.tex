\textbf{The \toolname{} pipeline.} Stage~1 uses Alloy to exhaustively enumerate minimal abstract execution graphs that satisfy a defense's leakage predicate, which is translated manually from the defense specification into the \toolname{} DSL. Stage~1.5 re-enumerates with loosened minimality, pinned to each Stage-1 graph, to reach more complex graphs. Stage~2 concretizes each graph into one or more x86 programs with annotations. Stage~3 runs each program on the defense's gem5 build under a non-invasive harness that applies the speculation and timing directives; an inspection program checks the resulting pipeline trace for the defense's transmission criteria inside the speculative window. Gray marks defense-specific parts and sources of truth.
