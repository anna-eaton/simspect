\textbf{The Alloy vocabulary shared by every SimSpect defense model.} Rows are the model's signatures and their fields (in Alloy every field is a relation), in declaration order; only the defense block (speculation contract, protection set, leakage function) differs between models. A Boolean is a \texttt{lone} field into a one-atom signature (\texttt{rBool}, \texttt{cBool}, \texttt{tBool}). Figures draw kinds without the \texttt{T} (\texttt{Load}), state as $r0$, $m0$ (\texttt{?} = unspecified), set Booleans as italic words (\textit{resolved}, \textit{committed}, \textit{xmit}), \texttt{spo} as row order, and \texttt{rf}/\texttt{ddi} as labelled arrows. The symmetry-breaking field \texttt{idx} is omitted.
